# anticode 0.1.36

- **OrcaRouter Free lewat OAuth.** Settings → Auth punya entri baru: PKCE ke
  `www.orcarouter.ai/auth` dengan callback localhost, key hasil tukar disimpan
  sebagai token panjang tanpa refresh. Kotak paste menerima kode maupun URL callback.
- **Hanya rute gratis.** Katalog akun OrcaRouter disaring ke `-free` (plus
  `orcarouter/free`), dan model berbayar ditolak sebelum kredensial dikirim. Tidak
  ada fallback ke wallet berbayar.
- **Penolakan gratis dijelaskan.** OrcaRouter menjawab 429 `free_rate_limited`
  saat workspace belum menautkan akun GitHub yang memenuhi syarat. Jawaban itu tidak
  lagi diperlakukan sebagai rate limit sementara, dan percakapan menyebut syaratnya.

Verifikasi: TypeScript, build, seluruh tes unit (87 file, 904 tes) termasuk tes baru
untuk PKCE, callback loopback, katalog gratis, dan penolakan model berbayar. Probe
key OrcaRouter nyata pada 12 November 2026: `/models` 200 (216 model, 6 rute gratis),
chat gratis 429 `err_free_access_denied` — syarat akun belum terpenuhi, bukan masalah
endpoint. Pengujian fixture bukan probe inference provider nyata atau benchmark
kemampuan model.
