# Anticode 0.0.100

## Perubahan

- Rotate menandai kredit output yang tidak cukup sebagai **out of usage** dan melewati rute tersebut untuk memilih akun/provider aktif lain yang memenuhi batas grup serta subscription/gratis.
- Pertanyaan agent dan jawaban pengguna tetap terlihat ketika giliran lama dilipat.
- ChatGPT dan Antigravity ditempatkan di awal Auth; provider API key di bagian bawah.
- Tab padat menggunakan ikon dan tooltip judul.
- Penolakan gambar oleh provider dapat dipulihkan dengan replay teks tanpa menghapus gambar dari transkrip.
- Diagnostik Copilot menyertakan jumlah model dan kebijakan; Antigravity menyertakan alasan kegagalan server. Ini bukan jaminan perbaikan koneksi provider nyata.

## Verifikasi

- Suite unit/integrasi penuh dan typecheck main/renderer lolos.
- 13 harness Electron terisolasi lolos: UI, desktop, free-auth, rotation-workflow, provider-keyring, route-capacity, workflow-fixes, run-resilience, session-recovery, multiple-accounts, native-subscriptions, agent-loop, subscription-usage.
- Fixture error 402 membuktikan penandaan out of usage dan penyelesaian giliran berikutnya melalui provider lain yang aktif.
- Paket macOS Apple Silicon berhasil dibangun; smoke test paket memastikan versi 0.0.100, jendela, dan preload API tersedia.
- Pengujian provider menggunakan fixture, bukan akun berbayar/gratis nyata atau benchmark coding.

## Batasan

- Paket macOS belum ditandatangani/notarized; macOS dapat menampilkan peringatan Gatekeeper.
- Release ini hanya menyediakan paket macOS Apple Silicon, bukan Windows/Linux/Intel.
- Permintaan filter agregat Usage Today/7D belum diimplementasikan dalam rangkaian commit ini.
