# Anticode 0.0.101

Seluruh delapan commit perubahan setelah 0.0.100 disertakan.

## Perubahan

- Usage menampilkan agregat seluruh model pada rentang Today/7D/30D/60D/All secara default; rincian tanggal tersedia melalui klik grafik dan direset ketika rentang berubah.
- Composer otomatis fokus ketika lampiran ditambahkan pada dashboard maupun sesi.
- Tab mempertahankan judul pendek selama ruang mencukupi; mode ikon menyediakan tombol close saat hover.
- Rotate dapat melewati rute yang menolak request dengan HTTP 413, tanpa menganggap kuota akun habis atau membuka fallback berbayar otomatis.
- Penolakan gambar hanya berlaku pada provider/akun dan model terkait, bukan seluruh provider dengan nama model sama. Pesan diagnostik membedakan penolakan rute dari kapabilitas model.
- Parser Codex mempertahankan alasan dan kode kegagalan pada beberapa bentuk event stream; perubahan ini memperjelas diagnosis, bukan jaminan perbaikan semua kegagalan Codex.
- Tes Electron ditambahkan untuk alur pertanyaan agent, agregasi Usage, fokus lampiran, tab padat dan penutupan tab, serta HTTP 413.

## Batasan

- Pengujian provider memakai fixture terisolasi, bukan akun provider nyata maupun benchmark coding.
- Paket yang diterbitkan: macOS Apple Silicon. Belum ditandatangani/notarized; peringatan Gatekeeper mungkin muncul.
- Jika semua rute aktif menolak ukuran request yang sama, HTTP 413 masih memerlukan pengurangan konteks/lampiran atau rute lain yang mendukung ukuran tersebut.
