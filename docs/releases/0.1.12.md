# Anticode 0.1.12

## Perbaikan utama

### Rotate melewati penolakan inference 403
- Model yang ditolak oleh provider (HTTP 403 inference) sekarang bisa Rotate ke model berikutnya dalam pool atau grup pengguna yang sama.
- Penolakan subscription safety check (status code tertentu) masih diblokir dan tidak dirotate otomatis.
- 429 rate limit tetap memicu `outOfUsage` dan cooldown biasa.

### Penanda out of usage tidak bertahan selamanya
- Model harian (non-free) akan dicoba ulang otomatis setelah **24 jam** bila tidak ada reset time dari provider.
- Model kartu gratis (`free`) akan ditinjau ulang setelah **7 hari**.
- Akun subscription tetap menunggu hingga provider melaporkan reset time, karena jendelanya bisa mingguan/bulanan.

### Penyimpanan scope akun
- Mark `outOfUsage` dengan `scope: 'account'` kini diwarisi oleh semua model dari provider yang sama.
- Contoh: bila `gpt-a` di `auth:codex` habis kuota, semua model `auth:codex` akan memakai mark tersebut hingga reset.
