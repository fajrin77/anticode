# Verifikasi perubahan desktop — 23 Oktober 2026

Cakupan: perubahan lokal di atas `6c1dac0`, termasuk pemilihan model/Rotate,
pin sesi, preview file, indikator Live routing, serta alur desktop dan ponsel.
Pengujian memakai profil sementara, workspace disposable dan provider fixture.
Kredensial pengguna tidak disalin dan inference provider nyata tidak dijalankan.

## Masalah yang diperbaiki

- Klik tab **Rotate usage** sebelumnya hanya membuka daftar pool. Sesi tetap
  memakai model manual. Sekarang klik itu langsung memilih Rotate untuk sesi
  tersebut, sambil membiarkan daftar grup terbuka. Provider biasa tetap perlu
  pemilihan model. Grup aktif, pin sesi lain dan batas routing dipertahankan.
- Agent dapat dihentikan oleh detektor narasi berulang saat membaca file berbeda
  dengan hasil baru. Output tool sukses kini dicatat sebagai bukti kemajuan,
  terpisah dari ID dan argumen panggilan. Narasi dengan hasil yang tetap sama,
  meski argumennya diganti, tetap mendapat arahan pemulihan lalu dihentikan.
- Menu **Open in** kartu file dapat tertutup composer. Menu kini memakai top
  layer browser, dengan posisi mengikuti kartu dan ruang viewport. Download
  melalui klik biasa diuji tanpa memaksa klik melewati elemen lain.
- Offset baca sesi idle dapat bergeser setelah pindah tab karena scroll anchoring
  saat layout pesan selesai. Pemulihan offset kini menunggu layout awal stabil;
  input wheel/touch membatalkan penyesuaian otomatis tersebut.

Skrip QA lama disesuaikan dengan UI saat ini: grup akun perlu dibuka,
provider Composer perlu diaktifkan secara eksplisit dalam fixture, field Models
berbeda dari Add API keys, gambar memakai dialog, dan download memakai menu
Open in. Pengujian posisi baca memakai jawaban yang benar-benar tersimpan di
main process; dialog attachment dan respons lambat dikendalikan agar pengujian
race tidak bergantung pada kecepatan mesin. Prompt ponsel saat run aktif diuji
sebagai antrean sesuai implementasi saat ini.

## Batas bukti

Ini bukan probe akun/provider nyata atau benchmark kemampuan coding model.
Hasil fixture tidak membuktikan entitlement semua alias, kapasitas kuota nyata,
atau kemampuan setiap model. Pengujian paket terbatas pada macOS arm64 di mesin
ini; Windows/Linux dan pembaruan melalui distribusi publik tidak diuji.
Build lokal tidak mem-publish release atau mengganti aplikasi pengguna yang
sedang menjalankan sesi aktif.
