# Penanganan DSML mentah — 23 Oktober 2026

Masalah: model/gateway dapat mengirim token kontrol DSML pada channel teks,
sehingga payload yang seharusnya berupa tool call terlihat sebagai jawaban.
Screenshot pengguna memperlihatkan bentuk token dengan spasi. Perbaikan dilakukan
di streaming `AgentSession`, sebelum event teks dikirim ke desktop/ponsel dan
sebelum respons diterima untuk eksekusi tool.

- Opening token ASCII, fullwidth, dan bentuk berspasi ditahan walau terpecah
  antar-chunk. Payload mentah tidak diparse menjadi perintah atau dieksekusi.
- Respons invalid dibuang sebelum tool di respons itu berjalan, termasuk
  respons campuran yang juga membawa tool call terstruktur.
- Agent menyimpan prosa aman yang sudah tampil, memberi pemberitahuan, dan
  meminta satu koreksi melalui native tool calling pada rute/model yang sama.
  Hasil tool yang sudah terkonfirmasi tidak dijalankan ulang.
- Jika koreksi kembali invalid, run berhenti dengan alasan yang jelas. Kesalahan
  protokol ini tidak memicu fallback akun/provider atau cooldown kuota.
- Contoh yang dikutip dengan backtick, pembahasan DSML biasa, HTML dan matematika
  tetap ditampilkan. Pemeriksaan final juga melindungi adapter response-only.
- Pesan lama yang sudah tersimpan tidak dimigrasi atau dihapus. Filter berlaku
  pada respons baru melalui agent; ini bukan parser umum semua format tool teks.

## Bukti

- `src/main/agent/toolMarkup.test.ts`: semua batas potongan token, chunk per
  karakter, token terpotong, batas buffer, prosa/HTML dan contoh backtick.
- `src/main/agent/loop.test.ts`: pemulihan ke native write, tanpa replay write
  terdahulu, retry terbatas, tanpa fallback, response-only dan respons campuran.
- `node scripts/verify-tool-markup.mjs`: Electron + SDK OpenAI-compatible + SSE
  lokal. Lima request total untuk dua skenario: pemulihan dengan approval tool,
  write tunggal dan hasil tool diterima, lalu penolakan dua respons invalid
  berturut-turut. UI, event dan snapshot tidak memuat payload DSML mentah.
- `npm test`: 70 file, 769 tes lulus. Percobaan pertama terkena timeout
  pada tes screenshot macOS (5 detik); pengulangan suite penuh tanpa proses
  Electron paralel lulus.
- `npm run build`: typecheck Node/renderer dan build produksi lulus.

Semua bukti memakai fixture terisolasi. Tidak ada probe provider nyata atau
benchmark kemampuan coding; tidak ada perubahan pada subscription, model pool,
kredensial atau sesi proyek pengguna. Perbaikan ini belum dipublish sebagai rilis.
